## 범위와 설정

공개 GESRes 영상 5개에서 짧은 클립 4개 전체와 긴 강연의 10초 구간 6개를
5fps로 샘플링해 총 323프레임을 처리했다. 긴 강연 전체 56분의 검출률이 아니다.
강연 구간은 앞서 본 5%, 20%, 40%, 60%, 80%, 95% 시점 주변이다.
클립 23프레임과 강연 300프레임으로 구성되며 임의의 성공 프레임만 모은 결과가 아니다.

- MediaPipe 0.10.32, Python 3.12.14, Mac Apple M4. CPU delegate 지정.
- Face Landmarker 최대 1개, Hand Landmarker 최대 2개, VIDEO 모드.
- 검출·존재·추적 임계값 모두 0.5. 구간마다 추적 상태 초기화.
- 별도 이동평균, 거리 보정, ROI crop을 적용하지 않은 기본 실행.
- 미검출 프레임도 보존. 얼굴 검출률을 실제 얼굴 노출 비율로 치환하지 않음.

실행 방법: [모듈 README](../../README.md).
구간·설정·해시·결과: [audit_results.json](audit_results.json).

## 시각 확인과 원인 진단

10개 구간의 contact sheet를 직접 확인했다. 이는 각 구간의 일부 프레임 확인이며,
323프레임 전부에 가시성 정답을 수동 부여하거나 전체 원본을 연속 시청한 것은 아니다.

1. **실제 얼굴이 보이는데 검출되지 않는 사례가 있다.** Lecturer2, Lecturer3 및
   강연의 사람 등장 표본에서 확인했다. 이들을 얼굴 미노출 또는 부적절 태도로
   자동 라벨링하면 검출기의 실패를 사람의 행동으로 잘못 학습하게 된다.
2. **실제 인물이 없는 화면도 있다.** 강연 670–680초 표본은 슬라이드 화면이며
   얼굴·손이 모두 미검출됐다. 자발적 화면 이탈과 같은 의미로 해석할 수 없다.
3. **손 누락 원인은 하나가 아니다.** 표본에서 손 겹침, 등 뒤 가림, 움직임의 블러,
   손이 보이는데도 검출되지 않는 경우를 확인했다. 어두운 구간에서는 두 검출군이
   같은 손 주변에 겹쳐 보이는 사례도 있어 손 개수를 실제 가시 손 개수로 확정하지 않는다.

얼굴의 작은 화면 내 크기가 원인인지 확인하기 위해 수동으로 선택한 프레임에
대해 **동일한 IMAGE 모드**로 전체 프레임과 얼굴 주변 crop을 비교했다.

| 시험 프레임 | 전체 화면 | 수동 crop |
|---|---|---|
| Lecturer2 sweep, 약 0초 | 미검출 | 검출 |
| Lecturer3 throw, 약 1초 | 미검출 | 검출 |
| 긴 강연, 약 164초 | 미검출 | 검출 |
| Lecturer1 pray, 약 0초 — 검출 대조 사례 | 검출 | 검출 |
| 긴 강연, 약 670초 — 슬라이드 대조 사례 | 미검출 | 미검출 |

이 결과는 **이 세 실패 프레임에서 crop이 검출에 도움이 됐음**을 보여준다.
작은 얼굴·주변 구도가 영향을 준다는 가설을 지지하지만, 해상도·얼굴 각도·배경의
효과를 분리한 실험은 아니다. 수동 선택 결과를 자동 crop의 일반 성능으로 보고하지 않는다.
구체적인 crop 좌표와 결과는 `audit_results.json`의 `crop_probe`에 기록했다.

## 다음 구현 결정

현재 자료는 추출·누락 처리 시험에 사용할 수 있다. 이 설정으로 곧바로 태도 학습에
투입하기에는 얼굴 누락이 많고 영상 맥락과 라벨도 준비되지 않았다.

후속 사용자 결정에 따라 **원본 프레임 → MediaPipe 직접 입력**을 유지한다.
YuNet과 자동 crop은 추가하지 않는다. 기존 crop 실험은 원인 진단 기록으로만 남긴다.
원본 위치·크기·누락 정보를 보존하는 XY 정규화와 이동평균을 구현했으며,
실행 범위와 한계는 [전처리 보고서](../guides/preprocessing.md)에 기록했다.

이 단계의 모델 학습·태도 라벨 확정은 수행하지 않았다. 원본별 이용 조건 검토도 남아 있다.
사용자가 지금 새 영상을 촬영하거나 라벨링할 필요는 없다.

## 검증 기록

- 실제 실행 10구간 완료, 323개의 JSONL 레코드와 추출 이미지 수 일치.
- 프레임 시각의 증가·구간 범위, 얼굴 478점·손 21점, 유한 좌표, 누락 상태 확인.
- 원시 결과에서 통계를 재계산하여 저장된 집계와 일치 확인.
- 분모 보존·빈 디코딩·잘못된 구간·중복 ID·FPS에 대한 단위 테스트 4개 통과.
- MediaPipe 1.0.1은 이 Mac에서 내부 Metal 초기화 중 종료됐고 0.10.32는 완료.
  이 현상의 전체 플랫폼 재현 여부는 검증하지 않았다.
- 이 기본 추출 실행에서는 거리 정규화·별도 이동평균을 적용하지 않았다.
  후속 전처리 실행과 구분한다. Torch 분류기와 분류 성능 측정은 아직 없다.
