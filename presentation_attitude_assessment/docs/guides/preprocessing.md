# 얼굴·손 좌표 전처리 v1

[문서 목차](../README.md)

실행일: 2026-09-07. 원본 프레임을 MediaPipe에 직접 입력하는 방식을 유지한다.
회사 구현의 정확한 복원이 아닌, 사용자가 승인한 재구현의 첫 전처리 기준이다.

## 변환 정의

MediaPipe의 이미지 크기 기준 XY를 먼저 픽셀 좌표 `p=(x·W, y·H)`로 바꾼다.
가로·세로 종횡비가 다른 영상을 같은 기하 구조로 다루기 위한 처리다.

얼굴 478점의 XY 최솟값·최댓값으로 bounding box를 만들고:

```text
c = (bbox_min + bbox_max) / 2
s = sqrt(bbox_width_px * bbox_height_px)
q = (p - c) / s
p_restored = q * s + c
```

얼굴과 손의 모든 XY에 같은 `c`, `s`를 적용한다. 균일 확대·축소와 평행 이동에
불변인 표현이며, 원근·고개 회전·표정에 대한 완전한 거리 보정은 아니다.
얼굴 box는 포즈·랜드마크 오차에도 변하므로 실영상에서 추가 검증이 필요하다.
최소 scale은 1픽셀로 정해 퇴화한 box를 거부한다. 회전 정렬은 하지 않는다.

`raw`에는 원래 XYZ·시각·검출·handedness를 모두 보존한다.
`anchor`에는 원본의 얼굴 중심·크기·box를 보존한다. 화면 이탈이나 얼굴 크기를
나중에 사용할 수 있으며 현재 전처리는 그 자체로 태도를 판단하지 않는다.
z는 얼굴·손 사이 기준을 통일하지 않고 원본에만 보존한다. 현재 특징은 XY만이다.

## 누락과 손 슬롯

- 얼굴 미검출·퇴화한 box: 얼굴 기준 정규화는 모든 슬롯에서 불가.
  손이 검출됐다면 원본 손 좌표는 유지하고 `face_anchor_unavailable`로 구분한다.
- `Left` / `Right`는 MediaPipe handedness 슬롯이다. 영상 반전 여부와 실제 좌우를
  독립적으로 확인하지 않았으며, 사람의 정체성이나 발표자 소속을 보장하지 않는다.
- 같은 쪽으로 두 손이 분류되면 해당 슬롯을 `duplicate_handedness`로 비운다.
- 좌우 분류 점수 0.7 미만은 `low_handedness_score`로 비운다. 이 값은 초기 휴리스틱이다.
- 이전 프레임 반대쪽 손목이 현재 손목에 훨씬 가까우면 `handedness_switch_suspected`로
  양쪽 슬롯을 분리한다. 거리 차이 여유는 화면 대각선 2%, 근접 범위는 15%다.
  이는 뒤바뀜 의심 경고이며 정답 ID 복원이 아니다. 손 교차·빠른 움직임도 경고할 수 있다.

원본 검출 여부와 전처리 유효 여부는 다르다. `valid`는 **해당 슬롯을 이 변환에 사용할
수 있는지**를 뜻하며 실제 얼굴·손 가시성 정답이 아니다. 무효 값은 `null`로 남긴다.
검출을 0 좌표로 대체하거나 누락을 보간하지 않는다.

## 이동평균 경계

기본값은 앞·현재·뒤 프레임의 중앙 3프레임 평균이다. 5fps에서는 인접 시점이
각 0.2초 간격이다. 업로드 완료 영상을 처리하므로 미래 1프레임을 사용할 수 있다.
단일 실시간 인과 필터로 그대로 사용하는 설계는 아니다.

**연속된 전체 창이 있을 때만 평균을 적용한다.** 창이 없는 구간 양끝과 1~2프레임
구간은 정규화 좌표를 유지한다. 초기 부분 창 평균에서 2프레임의 움직임이 같은 값으로
사라지는 것을 실측해 이 정책으로 수정했다. `smoothing_support`는 결측 0, 유지 1,
기본 전체 평균 3으로 기록한다.

평균 구간은 슬롯별로 나누며 다음 상황에서 끊는다.

- 얼굴·손 유효값 누락, 의심 손 슬롯.
- 입력 구간의 시작, 프레임 인덱스 공백, 예상 프레임 간격의 1.5배를 넘는 시간 공백.
- 입력 레코드에 `break_before=true`로 명시한 장면 경계.
- 얼굴 중심이 이전 얼굴 scale보다 크게 이동하거나 scale이 2배 이상 범위를 벗어남.

자동 장면 전환 검출이나 다중 인물 추적기는 구현하지 않았다. 위 마지막 기준은
급격한 변화에 대한 휴리스틱이며 모든 장면 전환·인물 변경을 잡는다고 보장하지 않는다.
검출 누락 복구나 흔들리는 기준점 자체의 별도 smoothing도 하지 않는다.

[실측 JSON](../history/preprocessing_results.json)에 입력 해시·코드 해시·설정·구간별 통계를 남겼다.

| 항목 | 결과 |
|---|---:|

| 손 좌우 뒤바뀜 의심 경고 | 11프레임, 정답 대조 미완료 |
| 비교 이미지 확인 | 유효 특징이 있는 클립 2개, 전체 11개 샘플 프레임 |

나머지 8구간은 얼굴 기준점을 만들지 못했다. 원본 손 좌표는 보존했지만,
얼굴에 대한 상대 손 좌표를 임의로 계산하지 않았다. 학습 준비가 끝난 323프레임을
확보했다는 의미가 아니다. 프레임별 좌표·미디어는 Git에서 제외한 로컬 산출물이다.

Lecturer1 pray의 유효한 연속 쌍 4개에서 정규화 좌표의 프레임 간 변화 RMS는
얼굴 0.03781 → 0.03477, Right 0.23626 → 0.23070이었다(얼굴 scale 단위).
연속 3점 차분 RMS는 얼굴 0.03151 → 0.01050, Right 0.10811 → 0.03604였다.
각 2개의 짧은 3프레임 구간에서 평균의 수학적 효과를 확인한 수치로,
실제 제스처와 검출 노이즈를 분리한 정확도나 노이즈 감소율이 아니다.

정치인 클립의 2프레임 구간은 수정 후 평균 적용 없이 움직임이 보존됐다.
비교 이미지에서는 좌표 역변환과 결측 유지, 짧은 구간 보존을 확인했다.
실제 동작이 과하게 평활화되지 않는다는 일반 결론은 내리지 않는다.

## 검증과 남은 범위

- 기존 4개 + 새 전처리 10개, 총 14개 테스트 통과.
- 평행 이동·균일 scale·영상 크기 변화 및 종횡비에 대한 계산 검증.
- 선형 동작 보존, 단일 점 급변 완화, 2프레임 동작 보존 검증.
- 누락·시간 공백·명시 경계·손 순서 변경·좌우 충돌·잘못된 입력 검증.
- 실제 323개 입력 레코드와 출력 `raw`의 일치, SHA-256, 유효 마스크·유한 좌표·집계 확인.
- 실제 유효 좌표의 정규화 → 원본 XY 역변환 최대 절대 오차 약 `2.78e-17`.
- 두 클립의 비교 MP4 생성과 11개 비교 프레임 시각 확인.

이 실험 당시에는 전처리 구현을 검증한 단계였다. 실제 거리 변화 실험, 충분한 연속 동작 표본,
손 경고의 정답 대조, 태도 라벨과 Torch 분류기 학습이 후속 과제였다.
다음 데이터 검토에서는 얼굴·손이 연속으로 보이는 카메라 대상 발표 후보를 우선한다.
사용자가 지금 새 영상을 촬영할 필요는 없다.
