# 발표 태도 평가: 재구현 기준 초안

[문서 목차](../README.md)

작성일: 2026-09-07 · 상태: 추출·전처리 구현, 라벨링 초안, GRU 테스트 학습 검증

이 문서는 크레버스 업무에 대한 사용자의 설명과 이번 개인 재구현의 설계를 구분한다.
회사 코드, 데이터, 학습 가중치를 복원하거나 포함하지 않는다.

## 사용자가 확인한 당시 업무

- 동영상 전체를 업로드하고, 영상 하나에 적절한 태도 / 부적절한 태도 하나를 출력했다.
- FFmpeg로 초당 일정 수의 프레임을 샘플링했다. 정확한 샘플링 빈도는 미확인이다.
- MediaPipe로 얼굴과 손의 랜드마크 좌표를 추출해 입력 특징으로 사용했다.
- 좌표 시퀀스에 이동평균을 적용해 노이즈를 완화했다.
- 촬영 거리 차이를 줄이기 위해 정규화한 것으로 사용자가 기억한다.
  구체적인 정규화 방식과 이동평균과의 적용 순서는 미확인이다.
- PyTorch 신경망으로 분류했다. 신경망 구조와 가변 길이 처리 방식은 미확인이다.
- 사용자가 영상을 직접 보고 레이블링했다. 정량적인 성능 수치는 확인되지 않았다.

## 당시 레이블링 판단

사용자는 좋은 발표 태도를 전반적으로 충족하는지 살펴보는 방식이라고 설명했다.
아래 항목을 모두 통과해야 하는 자동 AND 규칙이나 가중합이었다고 해석하지 않는다.

| 요소 | 사용자 설명 | 재구현에서 기록할 관찰 |
|---|---|---|
| 시선 | 시선을 잘 마주친다 | 상대를 향한 시선의 유지·이탈, 근거 구간 |
| 제스처 | 제스처를 적극 사용한다 | 설명에 어울리는 제스처, 반복 동작과 맥락 |
| 산만함 | 산만하지 않는다 | 산만하다고 판단한 구체적인 행동과 반복 구간 |
| 얼굴 노출 | 전체 프레임의 절반 이상에서 얼굴이 나타난다 | 실제 얼굴 노출 비율과 측정 방법 |
| 화면 이탈 | 얼굴을 자꾸 카메라 밖으로 이동하면 부적절하게 봤다 | 자발적 이탈과 촬영·편집 원인 구분 |

얼굴 노출 50% 이상은 확인된 판단 요소다. 이 조건만으로 적절 판정을 내리거나,
나머지 요소의 가중치·빈도·시간 임계값을 임의로 확정하지 않는다.

## 이번 재구현의 라벨링 절차 제안

1. **대상 영상의 맥락을 먼저 기록한다.**
   카메라를 상대하는 발표, 현장 청중을 상대하는 강연, 대화를 구분한다.
   우선 카메라를 상대하는 발표를 목표 맥락으로 가정하되, 원래 서비스의 상세 촬영
   지침까지 확인된 것은 아니다. 현장 강연의 옆보기나 칠판 보기를 자동으로 부적절로
   취급하지 않는다.
2. **평가 단위를 확정하고 전체를 본다.**
   원본 ID, 발표자 ID, 시작·종료 시간을 기록한다. 긴 강연에서 떼어낸 구간은
   해당 구간의 평가임을 명시한다. 짧은 제스처 클립의 인상을 원본 전체의 정답으로
   확장하지 않는다. 같은 원본·발표자의 파생 구간은 학습/평가에 나눠 넣지 않는다.
3. **관찰과 최종 판단을 나눠 적는다.**
   `appropriate` 또는 `inappropriate`에 근거 구간과 이유를 함께 기록한다.
   제스처의 양만으로 적절함을 결정하지 않고, 머리 방향을 실제 눈맞춤과 동일시하지 않는다.
   얼굴·손 관찰로 발표자의 성격이나 내면 상태를 추정하는 라벨을 만들지 않는다.
4. **불확실한 영상은 판정을 보류한다.**
   맥락 불일치, 화질 부족, 편집, 애매한 행동은 `needs_review`로 남긴다.
   이는 세 번째 예측 클래스가 아니라 주석 작업 상태다. 라벨은 `null`로 유지한다.
   에이전트 초안과 검토를 마친 라벨은 구분하고, 모델의 예측을 정답으로 되쓰지 않는다.
5. **대표 예시로 기준을 조정한다.**
   적절·부적절·경계 사례를 함께 검토하고, 판단이 바뀌면 루브릭 버전과 이유를 기록한다.
   가능하면 일부 영상을 독립적으로 중복 라벨링해 불일치 원인을 확인한다.

### 얼굴 노출과 검출 실패의 구분

- 실제 얼굴 노출 비율과 MediaPipe 검출 성공률은 다른 값이다.
- 얼굴이 보이는데 검출기가 실패한 프레임을 사용자 태도의 문제로 라벨링하지 않는다.
- 균등 샘플링으로 구한 비율은 추정치라고 표시한다. 원본 전체 프레임에서 측정한 값과
  혼동하지 않으며, 50% 부근의 사례는 더 촘촘하게 확인한다.
- 분모는 정해진 평가 구간 전체다. 얼굴이 없는 프레임을 먼저 삭제해 비율을 높이지 않는다.
- 슬라이드 전환·카메라 이동 때문에 얼굴이 보이지 않는 영상은 촬영 맥락의 문제로
  검토한다. 발표자의 반복적인 화면 이탈과 구분한다.
- 손이 화면 밖에 있거나 검출에 실패했다는 사실만으로 제스처 부족을 확정하지 않는다.

## 라벨링 예시: 모두 가상 설명

아래 사례는 기준 설명용이며, 확보한 영상에 실제로 붙인 라벨이 아니다.
시선·행동의 구체적인 관찰이 가능한 영상이라는 전제다.

| 가상 사례 | 제안 판정 | 이유 |
|---|---|---|
| 얼굴이 대부분 보이고 상대를 향해 설명하며 자연스러운 손짓을 사용한다. 잠깐 메모를 본다. | 적절 초안 | 일시적인 시선 이탈만으로 전체를 부적절하게 보지 않음 |
| 카메라 대상 발표 중 본인이 반복해서 화면을 벗어나 실제 얼굴 노출이 40%다. | 부적절 초안 | 얼굴 노출 기준 미달과 반복적인 자발적 이탈 |
| 얼굴은 보이지만 설명과 무관한 손·고개 동작을 지속적으로 반복해 산만하게 보인다. | 부적절 초안 | 움직임의 양이 많다는 사실과 적절한 제스처를 구분 |
| 얼굴과 시선은 안정적이지만 손짓이 거의 없다. | 검토 필요 | 제스처 부족 하나로 판정을 확정하는 규칙은 미합의 |
| 현장 강연자가 청중·칠판을 번갈아 본다. | 맥락 검토 필요 | 카메라를 상대하는 발표와 눈맞춤의 대상이 다름 |
| 슬라이드 화면 때문에 얼굴 노출이 절반 미만이다. | 영상 적합성 검토 필요 | 발표자 행동으로 인한 화면 이탈인지 구분 불가 |
| 얼굴은 보이지만 저해상도·블러로 눈과 손의 관찰이 어렵다. | 품질 검토 필요 | 검출 실패를 부적절 태도의 정답으로 쓰지 않음 |

실제 미라벨 샘플은 [데이터 검토 기록](../data/data_review.md)과
[샘플 목록](../data/sample_inventory.json)에 별도로 남긴다.
새 영상 검토에는 [주석 템플릿](../data/annotation_template.json)을 사용한다.

템플릿의 `source_kind`는 `real` / `synthetic`, `presentation_context`는
`camera_addressed` / `live_audience` / `conversation` / `unknown`으로 기록한다.
`annotation_status`는 `unlabeled` / `draft` / `needs_review` / `reviewed`로 구분한다.
`proposed_label`과 `final_label`은 `appropriate` / `inappropriate` 또는 `null`이다.
확정 전에는 `final_label`을 비워 둔다. 템플릿 자체는 학습 데이터로 수집하지 않는다.
`split`은 적합성·이용 조건·라벨 검토를 마친 뒤 발표자와 원본 단위로 정한다.

## 구현 및 검증 경계

- GRU와 가변 길이 처리는 이번 재구현의 구현이며 당시 구현 사실이 아니다.
- 랜드마크 추출은 공개 샘플 10구간, 323프레임에서 실행했다.
  [추출 검증 보고서](../history/landmark_audit.md)에 검출 누락과 수동 crop 진단 결과를 기록했다.
- 원본을 MediaPipe에 직접 입력하며 YuNet과 얼굴 crop은 추가하지 않는다.
- 얼굴 중심·크기를 이용한 XY 정규화와 3프레임 이동평균을 구현·시험했다.
  z는 원본에 보존하고 현재 특징에서는 제외한다. 이는 새 설계이며 당시 방식의 복원이 아니다.
  실영상에서의 효과 검증 한계는 [전처리 보고서](preprocessing.md)에 기록했다.
- 학습 가능한 실영상, 합성 데이터, 코드 테스트용 데이터를 구분한다.
- 현재 실제 태도 라벨 0건, 실제 태도 데이터 학습 0회, 분류 성능 측정 0회다. 테스트용 합성 좌표의 학습 파이프라인은 실행했다.
- [전체 영상 파이프라인](whole_video_pipeline.md)은 영상 경로 하나에서 특징 시퀀스·결측 마스크·시각 정보를 순차 저장한다. 작은 GRU와 가변 길이 배치는 [학습 파이프라인](gru_training.md)에서 구현했다.
- MediaPipe 추출 동작을 검증한 범위와 태도 분류 성능 검증을 구분한다.
