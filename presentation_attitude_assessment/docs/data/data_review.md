| GESRes | 공개 OSF API 목록 확인, 총 7파일 다운로드 성공, 파일별 권한 문서 대조 | 현장 강연·대화 등이며 카메라 대상 발표와 맥락이 다름. 제스처 주석은 태도 정답이 아님 | 추출·누락 처리 시험 후보. 태도 학습 적합성은 미확정 |
| 3MT_French | 공개 API는 restricted, 비로그인 파일 목록은 비어 있음 | 현장 발표 종합 평가가 얼굴·손 태도 평가와 동일하지 않음 | 실제 목록 확보 전까지 보류. 신청을 보내지는 않음 |
| First Impressions V2 | 학습 파일 접근 시 로그인 요구 | 카메라 대상 발화지만 평균 약 15초, 손 가시성 미확인 | 로그인 후 파일·세부 조건 검토 필요 |
| MIT Interview | 학술 이메일을 통한 신청 필요 | 면접 영상이며 목표 태도 라벨과 다름 | 신청·파일 확보는 미진행 |
| POM | 등록 폼과 연구용 사용 확인 요구 | 의견 표현 영상, 얼굴·손 구도 미확인 | 등록·파일 확보는 미진행 |
| PATS | 공식 배포 설명 확인, 이번 검토에서 파일 확보하지 않음 | OpenPose 특징·원본 링크 기반이며 태도 라벨 없음. 원본 접근과 구도 추가 확인 필요 | 후순위 후보 |
| BEAT2 | 공식 프로젝트 설명 확인, 파일 확보하지 않음 | 3D 모션 형식으로 원본 발표 영상·MediaPipe 좌표와 다름 | 동작 연구·렌더링 후보, 즉시 학습용 아님 |

접근 확인과 파일별 조건의 상세 근거는 [공개 영상 접근 검토](data_access_review.md)에 있다.
대용량 전체 데이터의 확보나 모든 영상의 이용 조건 확인을 완료한 상태는 아니다.

## 보관과 재현

- 로컬 미디어: 저장소 루트의 `.local-data/presentation-attitude/gesres/`
- 메타데이터·출처·SHA-256: [sample_inventory.json](sample_inventory.json)
- 미디어는 Git에서 제외한다. 목록의 로컬 경로는 다운로드한 이 작업 환경 기준이다.
- 파일별 다운로드 주소와 해시를 남겼지만, 링크의 영구 가용성을 보장하지 않는다.
- GESRes의 `Licensing_information.pdf` 2페이지를 배포 목록·CSV와 대조했다.
  MIT 원본은 CC BY-NC-SA 4.0, AOC는 배포자가 Public Domain으로 명시한다.
  다른 일부 원본에는 ID 불일치·권한 문서와 실제 배포 목록의 충돌이 있다.
  [파일별 검토](data_access_review.md)를 따르며 데이터셋 전체에 단일 영상 라이선스를 적용하지 않는다.

## 다음 작업과 완료 조건

1. 기본 추출과 [전처리 시험](../guides/preprocessing.md)은 완료했다. 사용자 결정에 따라
   MediaPipe 직접 입력을 유지한다. 현재 323프레임 중 얼굴 기준 정규화가 가능한
   프레임은 9개였다. 접근·조건 확인 후 MIT 심리학과 의회 발언의 전체 원본을 추가 확보했다.
   [MIT 연속 검증](../history/mit_continuity_review.md)을 완료했으며 전체 태도 학습용 채택은 보류했다.
   다음은 의회 발언 원본에 같은 연속 검출 검사를 적용하는 것이다.
2. 카메라를 상대하는 발표 후보는 접근 가능성, 얼굴·손 가시성, 영상 전체 맥락,
   원본별 이용 조건을 함께 검토한다. 촬영 환경이 다른 영상은 별도 도메인으로 남긴다.
3. 적합한 후보에만 [기준 초안](../guides/presentation_attitude.md)을 적용해 라벨 초안과
   근거 구간을 작성한다. 검토되지 않은 에이전트 초안을 확정 정답으로 보고하지 않는다.

현재 사용자에게 촬영이나 다운로드를 요청할 필요는 없다.
대표적인 경계 사례가 생기면 한 번에 소수의 사례로 기준을 조정한다.
