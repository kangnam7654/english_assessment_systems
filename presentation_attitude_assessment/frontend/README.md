# 발표 영상 분석 UI

React + TypeScript + Vite로 구현한 로컬 포트폴리오 시연 화면이다.
영상 선택·드롭 → 브라우저 미리보기 → 업로드 → 상태 조회 → 실제 특징 분석 결과 확인을 연결한다.
사용자가 처리 모드를 고르지 않으며 현재 요청은 `features`로 고정한다.
실제 태도 학습 체크포인트가 없으므로 모델 판정을 만들어서 표시하지 않는다.

## 실행

저장소 루트에서:

```sh
npm ci --prefix presentation_attitude_assessment/frontend
npm run build --prefix presentation_attitude_assessment/frontend
uv run --locked presentation-serve
```

별도 터미널에서:

```sh
uv run --locked presentation-worker
```

[추론 UI](http://127.0.0.1:43187/ui/)를 연다. 빌드한 정적 파일을 FastAPI가 `/ui/`에서 제공하므로
별도 프런트엔드 서버는 필요하지 않다. 빌드 없이 시작하면 기존 API만 제공한다.
이 경우 빌드 후 API를 재시작한다. 같은 origin의 `/jobs`, `/health`를 사용하며 CORS를 추가하지 않았다.
API와 워커는 같은 `PAA_DATA_DIR`를 사용해야 한다.

개발 중 자동 갱신이 필요하면 API·워커를 켠 채 다음 명령을 사용한다.

```sh
npm run dev --prefix presentation_attitude_assessment/frontend
```

개발 주소는 `http://127.0.0.1:43188/ui/`이며 API 43187로 프록시한다.
포트 충돌 시 자동으로 다른 포트를 고르지 않는다. Node.js 22.23.1에서 빌드를 확인했다.

## 화면 동작

- 전체 영상 하나를 업로드한다. 파일 크기는 `/health`의 제한값을 사용하고 서버가 다시 검사한다.
- 업로드 전송률과 분석 상태를 구분한다. 분석 퍼센트·남은 시간을 추정해서 표시하지 않는다.
- 약 2초마다 상태를 조회한다. 성공 시 결과를 읽고, 실패 시 재시도 버튼을 제공한다.
- 조회 통신 오류는 작업 실패로 바꾸지 않는다. 마지막 상태를 유지하며 연결을 다시 확인한다.
- 업로드 응답을 잃으면 자동 재업로드하지 않는다. 서버 접수 여부가 불명확할 수 있다.
- 최근 작업 ID만 브라우저 localStorage에 보관한다. 새로고침 후 상태·결과를 복원하지만 원본
  미리보기 파일은 보관하지 않는다. 서버에는 기존 파일과 시도 이력이 남는다.
- 결과 JSON 저장은 실제 결과 API 응답을 내려받는다. 검출 비율은 태도 점수가 아니다.
- 브라우저가 지원하지 않는 코덱은 미리보기 불가 안내를 표시한다. 서버 FFmpeg는 별도로
  디코딩하므로 브라우저 미리보기 가능 여부와 분석 성공 여부는 다를 수 있다.
- 현재 워커 heartbeat가 없으므로 API 접근 성공을 워커 준비 완료로 표시하지 않는다.

## 코드

| 파일 | 역할 |
|---|---|
| `src/api.ts` | API 타입·오류·업로드 전송률 |
| `src/useAnalysis.ts` | 작업 상태 조회·재시도·최근 작업 복원·요청 정리 |
| `src/App.tsx` | 영상 입력·결과·오류 화면 |
| `src/style.css` | 공통 토큰·데스크톱 두 열·모바일 한 열·접근성 스타일 |

`npm run build`로 TypeScript 검사와 배포 빌드를 수행한다.
2026-09-08 Chrome에서 실제 공개 클립과 H.264 변환본 업로드·특징 결과·영상 재생·JSON 저장·
새로고침 복원·잘못된 확장자 거절·손상 영상 실패와 재시도를 확인했다.
데스크톱 1536×1024, 모바일 390×844에서 확인했으며 실제 태도 모델 추론 검증은 아니다.
공개 영상과 테스트 산출물은 UI 소스에 포함하지 않는다.

## 모델 판정 화면 예시

`http://127.0.0.1:43187/ui/?preview=assessment`에서 적절한 태도·부적절한 태도·판정 불가
화면을 전환할 수 있다. `ModelPreview.tsx`의 가상 응답을 `Results.tsx`의 실제 결과
컴포넌트로 렌더링하며, 모든 수치가 UI 예시임을 표시한다. 실제 영상·학습 모델을 사용하지
않고 API 요청, 작업 생성, 브라우저의 최근 작업 기록 변경도 하지 않는다.
일반 `/ui/`의 업로드 동작과 모델 체크포인트 정책은 동일하다.
