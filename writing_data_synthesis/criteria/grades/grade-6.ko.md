# 6학년 영어 글쓰기 루브릭

[전체 학년](../README.md) · [실행용 JSON](grade-6.json)

**대상: 미국 6학년 · 평가 영역: 내용, 구성, 표현, 문법 · 영역별 1–4점**

이 문서 하나에서 해당 학년의 글 유형별 요구사항과 점수별 기준을 확인할 수 있습니다. 점수는 이 학년의 기대 수준 안에서 판단하며 총점은 계산하지 않습니다.

## 글 유형별 요구사항

### 논증문

주장을 분명히 제시하고 관련 근거와 명확한 추론으로 뒷받침한다. 주장·이유·근거를 연결하고 격식을 갖춘 문체와 논증에 맞는 결론을 쓴다. 반론은 필수가 아니다.

참조 성취기준: CCSS.ELA-Literacy.W.6.1.a, CCSS.ELA-Literacy.W.6.1.b, CCSS.ELA-Literacy.W.6.1.c, CCSS.ELA-Literacy.W.6.1.d, CCSS.ELA-Literacy.W.6.1.e

### 정보문

주제를 소개하고 분류·비교·인과관계 등 적절한 구조를 사용한다. 사실·세부 내용·예시로 발전시키고 연결 표현, 정확한 관련 용어, 격식 있는 문체와 결론을 갖춘다.

참조 성취기준: CCSS.ELA-Literacy.W.6.2

### 서사문

상황과 화자·인물을 설정한다. 대화·속도 조절·묘사와 시간·장소 전환, 정확한 감각 묘사로 논리적인 사건의 흐름과 결말을 만든다. 관점 설정을 필수로 요구하지 않는다.

참조 성취기준: CCSS.ELA-Literacy.W.6.3

## 언어·문법에서 보는 내용

대명사의 격·수·인칭과 강조 용법을 적절히 사용하고 모호한 지시를 줄인다. 삽입 표현의 쉼표·괄호·대시, 대문자·철자를 적용한다. 문장 형태를 다양하게 선택하면서 문체와 어조를 유지한다.

## 점수별 기준

1점은 제한적, 2점은 발전 중, 3점은 해당 학년의 기대 수준 충족, 4점은 효과적이고 일관된 수행입니다. 아래 공통 척도를 위의 학년·글 유형별 요구사항에 맞춰 적용합니다.

### 1. 내용·과제 수행

*과제에 답하고, 생각을 적절한 설명이나 근거로 발전시켰는가?*

| 점수 | 평가 기준 |
| --- | --- |
| 1 | 의미 있는 글은 있지만, 과제에 대한 답변이나 관련 내용의 발전이 매우 제한적이다. |
| 2 | 과제에 부분적으로 답한다. 생각이나 근거가 고르지 않고, 막연하거나 일부 내용이 주제에서 벗어난다. |
| 3 | 과제에 분명하게 답한다. 해당 학년에 맞는 관련 생각과 충분한 설명·근거를 제시한다. |
| 4 | 과제의 목적에 맞춰 내용을 깊이 있게 발전시킨다. 해당 학년 안에서 세부 내용과 근거를 효과적으로 선택한다. |

### 2. 구성·연결

*내용의 순서와 연결을 독자가 자연스럽게 따라갈 수 있는가?*

| 점수 | 평가 기준 |
| --- | --- |
| 1 | 내용의 관계나 순서를 이해하기 어렵다. 필요한 구분과 연결이 대부분 부족하다. |
| 2 | 일부 구성이 드러나지만, 내용의 누락·반복이나 약한 연결 때문에 흐름이 끊긴다. |
| 3 | 생각이나 사건이 해당 학년에 맞게 일관된 순서로 이어진다. 필요한 연결과 시작·마무리를 갖춘다. |
| 4 | 목적에 맞는 순서와 효과적이고 다양한 연결이 글 전체의 흐름을 살린다. 내용 구분도 목적과 학년에 적절하다. |

### 3. 언어 표현

*단어·문장·어조가 의미를 명료하게 전달하는가?*

| 점수 | 평가 기준 |
| --- | --- |
| 1 | 부정확하거나 반복적인 표현 때문에 뜻을 이해하기 어렵다. 적절한 표현을 사용하는 능력이 제한적이다. |
| 2 | 뜻은 일부 전달되지만, 어휘·문장 형태·어조가 고르지 않거나 과제에 잘 맞지 않는다. |
| 3 | 어휘·문장·어조가 뜻을 명료하게 전달하며 학년, 글 유형, 독자에게 적절하다. |
| 4 | 정확한 어휘, 효과적인 문장, 일관된 어조가 의미를 더 잘 전달한다. 불필요하게 복잡한 표현에 의존하지 않는다. |

### 4. 문법·표기

*해당 학년에서 요구하는 문법·철자·구두점 등을 적절하게 사용하는가?*

| 점수 | 평가 기준 |
| --- | --- |
| 1 | 해당 학년의 문법·철자·구두점 오류가 자주 나타나 의미 이해를 반복적으로 방해한다. |
| 2 | 일부 규칙을 지키지만 반복되는 오류가 읽기를 방해하거나 때때로 뜻을 흐린다. |
| 3 | 해당 학년의 규칙을 대체로 지킨다. 작은 오류가 있어도 의미와 가독성은 유지된다. |
| 4 | 판단할 수 있는 충분한 글에서 규칙을 일관되게 지킨다. 드문 작은 오류는 읽기를 방해하지 않는다. |

## 출처 사용

**제공 지문이 있는 논증문·정보문에서만 평가합니다.**
논증문은 지문이 필수이고 정보문은 선택입니다. 서사문에는 이 항목을 적용하지 않습니다.

| 점수 | 평가 기준 |
| --- | --- |
| 1 | 지문에서 가져온 정보의 출처를 대부분 밝히지 않거나 의미를 왜곡한다. 상당한 분량을 옮겨 쓰면서 자신의 표현과 구분하지 않는다. |
| 2 | 일부 출처는 밝히지만, 출처 표시·바꿔 쓰기·인용의 정확성이나 과제가 요구한 출처 기록이 고르지 않다. |
| 3 | 학년에 맞게 출처를 밝힌다. 바꿔 쓰기와 인용이 원래 의미를 유지하며 필요한 출처 기록을 갖춘다. |
| 4 | 출처를 명확하고 자연스럽게 밝힌다. 정확한 바꿔 쓰기·인용과 과제에 맞는 출처 기록으로 가져온 내용을 효과적으로 구분한다. |

출처를 명확히 표시하고 의미를 유지한 바꿔 쓰기·인용을 평가합니다. 출처 목록은 과제가 요구할 때만 적용합니다.

해당하지 않는 과제는 **‘적용 안 함’**으로 표시합니다. 0점으로 처리하지 않습니다.

## 판정과 결과

각 영역은 실제 글의 근거를 바탕으로 독립적으로 판단합니다. 같은 문제를 여러 영역에서 반복 감점하지 않으며, 성격·동기·연구 과정을 추정하지 않습니다. 단어 수나 문단 수를 일률적으로 요구하지 않습니다.

원점수 1·2·3·4점의 표시값은 각각 0.00·33.33·66.67·100.00입니다. 프로그램이 계산하는 척도상의 위치이며 정답률이나 학년 간 실력 비교 점수가 아닙니다. 출처 사용이 해당하지 않으면 점수 없이 ‘적용 안 함’으로 표시합니다.

주제에서 벗어난 글도 다른 영역은 평가할 수 있습니다. 평가할 텍스트가 부족하거나 영어 글로 평가하기 어려운 경우에는 모든 점수를 비우고 ‘평가 불가’로 표시합니다. 학생이 직접 쓴 텍스트만 대상으로 하며 그림·구술·성인 대필은 포함하지 않습니다.

공개 자료를 재구성한 포트폴리오용 기준입니다. Mock으로 실행 흐름을 확인했으며 실제 평가 정확도와 교육적 타당성은 검증하지 않았습니다.
