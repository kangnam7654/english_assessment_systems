## 수집한 자료

2026년 9월 8일 기준 루브릭 16개와 CCSS 문서 1개를 수집했습니다.
‘전체’는 이 수집 범위를 뜻하며 미국의 모든 루브릭을 망라한다는 의미는 아닙니다.

| 출처 | 범위 | 원래 척도 |
| --- | --- | --- |
| UEN 9개 | K–2, 학년별 세 글 유형 | 내용·구성 1–4, 문법·표기 0–2 |
| Smarter Balanced 5개 | 의견문·정보문 3–5, 논증문·설명문 6–11, 서사문 3–8 | 글쓰기 두 영역 1–4, 문법·표기 0–2 |
| Oregon 2개 | 고등학교 서사문 및 정보문·논증문 | 여섯 영역 1–6, 정보문·논증문에는 출처 사용 추가 |
| CCSS ELA | K–12 글쓰기·언어 성취기준 | 점수표가 아님. 고등학교는 9–10, 11–12학년군 |

UEN 발행 버전은 확인되지 않았습니다. Smarter Balanced는 2022년 8월 개정본,
Oregon은 2019년 채택본입니다. Oregon 자료는 12학년 전용 규준이 아닙니다.
CCSS 인쇄 페이지 기준 글쓰기는 19–21·42–47쪽, 언어는 26–29·52–55쪽입니다.

## 재구성한 방법

내용·과제 목적과 구성을 나누고, 관찰 가능한 어조·단어 선택·문장 흐름은 언어 표현으로 묶었습니다.
문법·표기는 새 1–4단계 설명으로 작성했습니다. 출처 표시는 근거의 질과 구분해 필요한 과제에만 적용합니다.
UEN에 모든 공통 영역이 독립적으로 있는 것은 아니며, 저학년 언어 표현은 언어 성취기준을 참고한 프로젝트 추가 설계입니다.

영역별 분리·통합 이유는 비교표에 남겼습니다. 기존 기관 점수를 환산하거나 원래의 비중을 그대로
가져오는 방식은 아닙니다. 학년별 기대 수준 안에서 새로 평가하며 학년 간 실력 비교 점수로 사용하지 않습니다.
최종 글에서 확인할 수 없는 성격·동기·연구 과정은 추정하지 않습니다. 그림·구술·성인 대필도 평가 범위 밖입니다.

프로젝트 루브릭은 평가할 글이 부족하거나 비영어 텍스트인 경우 점수를 비웁니다. 주제 이탈은
영역별로 평가할 수 있습니다. 이는 원본 기관의 NS 정책과 구분됩니다. 기존 기관별 어댑터는
UEN·Smarter Balanced의 NS 범주를 보존합니다. Smarter Balanced의 과제 목적 이탈에서는 원본의
문법 항목을 채점할 수 있어도 앱은 전체 점수를 보류합니다. Oregon의 `insufficient_evidence`는
공식 NS가 아닌 프로젝트 보류 정책입니다.

## 재현과 기존 기록 호환

실행에서는 확정된 학년별 파일을 읽습니다. 템플릿은 재구성 이력으로 보존하며,
모듈 폴더에서 `python -m writing_synthesis.cli.materialize_project_rubrics --check`로 완성본과의 일치를 확인할 수 있습니다.
`--check`를 빼면 학년별 JSON을 다시 생성하므로 의도적으로 수정할 때만 사용합니다.

기존 기관별 요청·목록·저장 기록은 이곳의 요약본과 메타데이터를 계속 참조합니다.
기존 기본 경로는 유지했고, `project-writing-v1`을 명시하면 확정된 학년별 루브릭을 선택합니다.
각 실행에는 출처·기준 해시, 선택한 성취기준, 실제 프롬프트와 학년 파일 해시를 남깁니다.
Mock 검증은 형식·실행·저장 흐름을 확인하며 실제 평가 정확도나 사람과의 일치도를 뜻하지 않습니다.
